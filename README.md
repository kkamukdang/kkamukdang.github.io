## 1. 「이건 이미 기록해 뒀어요」 뺐습니다

같은 링크를 다시 눌러도 그냥 같은 화면이 보입니다.
"이미 했다" 는 말은 잘못한 것처럼 읽힐 수 있어서요.

기록이 두 번 쌓이지 않는 것은 `lastSeen` 이 막아주니 화면에서 설명할 필요가 없습니다.

**「이 기기에는 기록이 없어서 여기서부터 시작해요」는 남겼습니다.**
이건 알려주지 않으면 왜 처음부터인지 알 수 없으니까요.

## 2. 기록 보관 안내

「다시 만나기」 하단, 도장판 아래에 한 줄 넣었습니다.

```
기록은 이 브라우저에만 저장돼요.
기기를 바꾸거나 방문 기록을 지우면 사라집니다.
```

**여기에 둔 이유** — 도장판과 카운터를 본 직후가 "이게 어디에 남는가" 를
가장 궁금해할 자리입니다. 홈에 두면 아직 쌓인 것이 없어 와닿지 않고,
푸터에 두면 눈에 안 띄어요.

작게 두었습니다. 경고가 아니라 알려두는 것이니까요.

## 날짜에 대한 답

두 자리의 날짜가 다릅니다.

| 어디 | 무슨 날짜 |
|---|---|
| 메일 도착 화면 `9월 18일에 다시 만나요` | **방금 누른 그 표현** 하나의 다음 만남 |
| 큐가 비었을 때 `다음은 9월 18일` | 남은 표현 **전체 중 가장 빠른** 날 |

도착 화면은 방금 처리한 것만 알려주고, 다른 표현의 일정은 건드리지 않습니다.

## 지금 메일 딥링크 설정

| | |
|---|---|
| 메일에 정답 | 넣지 않음 (문제만) |
| 버튼 | `ok` · `no` 두 개 |
| `ok` | 14일 뒤 · 세 번 연속이면 졸업 |
| `no` | **내일** (「자신 없어요」와 같은 규칙) |

다르게 하고 싶으시면 `again.astro` 의 `record()` 함수에서 날짜만 바꾸면 됩니다.
