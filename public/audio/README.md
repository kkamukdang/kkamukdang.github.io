# 음성 파일 두는 곳

지금은 브라우저 내장 음성(speechSynthesis)으로 읽어주고 있어서 이 폴더는 비어 있어도 됩니다.
음질을 올리고 싶을 때만 쓰세요.

## 쓰는 법

1. 회차별 폴더에 mp3 를 넣습니다.  →  public/audio/001/scene-1.mp3
2. YAML 에서 그 파일을 가리킵니다.  →  Speak 컴포넌트의 audio 속성

파일이 있으면 그 파일을 재생하고, 없거나 실패하면 자동으로 브라우저 음성으로 넘어갑니다.
그래서 일부 문장만 먼저 녹음해도 페이지가 깨지지 않아요.

## 비용

GitHub Pages 는 정적 파일을 무료로 서빙합니다. 별도 서버가 필요 없습니다.
저장소 1GB, 트래픽 월 100GB 가 권장 한도예요.
mp3 한 문장이 20KB 안팎이니 회차당 30문장이면 약 600KB,
100회차를 채워도 60MB 수준이라 한도에 한참 못 미칩니다.
